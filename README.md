# Work-Examples
WORK EXAMPLES

1.	Customer Sentiment & Behavior Analysis (Yelp Data)

Objective
Analyze customer reviews to understand how sentiment impacts business ratings and customer behavior.

Dataset
•	250K+ Yelp reviews 
•	100+ businesses 

Approach
•	Cleaned and processed unstructured text data 
•	Applied NLP-based sentiment analysis 
•	Used clustering and network analysis to identify customer segments 

Key Insights
•	Positive correlation between sentiment and ratings (r ≈ 0.49) 
•	Majority of reviews skew positive 
•	Key drivers: service quality, food, ambiance 

Tools
R, NLP, Sentiment Analysis, Clustering Network Analysis


2.	Residential Property Database & Price Analysis 

Objective
Build a data pipeline to analyze housing prices and identify key drivers of property value.

Dataset
•	13K+ property records 
•	25+ features (price, size, location, demographics) 

Approach
•	Designed PostgreSQL database 
•	Wrote SQL queries for data extraction and analysis 
•	Performed EDA and feature analysis 
•	Built predictive models (Lasso, Random Forest) 

Key Insights
•	Random Forest achieved best performance (RMSE ≈ 0.064) 
•	Key drivers: square footage, bathrooms, construction quality 
•	Strong geographic variation in housing prices 

Tools
SQL, PostgreSQL, R, Machine Learning
